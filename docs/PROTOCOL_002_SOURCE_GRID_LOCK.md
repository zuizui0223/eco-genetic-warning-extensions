# Protocol 002 planned source-grid lock

## Purpose

The full planned Stage I source-grid manifest contains 10,125 retained rows. It
is deterministic and can be generated by:

```bash
protocol002 write-source-grid-plan
```

Instead of committing the multi-megabyte full manifest, this PR commits a
lightweight lock artifact:

```text
artifacts/protocol002/source_grid_planned_lock.json
```

The lock stores:

- the planned row count;
- grid constants;
- status counts;
- `simulation_result_present = false`;
- a SHA-256 digest of the full generated manifest.

## Command

```bash
protocol002 write-source-grid-lock \
  --output artifacts/protocol002/source_grid_planned_lock.json \
  --force
```

## Interpretation

This artifact is a planning lock only. It does not contain H1 source results and
is not Type S ecological evidence.

The committed lock must match `planned_source_grid_lock_artifact()` exactly.
The digest must match `planned_source_grid_artifact()` serialized with sorted
keys and compact separators.

## Next gate

After this lock is merged, the next implementation step is a source-runner
interface that can fill these planned rows with retained attempt statuses. The
first runner PR should still use a tiny deterministic fixture before launching
the full source-reconstruction campaign.
