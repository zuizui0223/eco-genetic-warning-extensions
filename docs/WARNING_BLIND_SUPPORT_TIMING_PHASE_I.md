# Warning-blind support/timing decomposition Phase I

## Question

Phase H showed that one fixed trait- and capacity-constrained rewiring rule substantially recovered network structure and match-weighted support after partner loss, yet the functional-loss regime remained R3 rather than returning to R4.

Phase I asks the unresolved causal question:

> Was Phase-H non-rescue caused by insufficient support magnitude, by delayed recovery/path dependence, or by an independent topology channel?

The last possibility must be handled carefully. In the current closure, network topology affects the eco-genetic life cycle only through the match-weighted support multiplier. There is no second topology-to-demography or topology-to-trait operator. Therefore topology-only manipulations are **representation-null controls**, not an independent biological topology test.

## Prospective condition set

All conditions use fresh five master seeds × 20 replicates, the same prepared source within a replicate, the same partner-loss identity, the same deterioration schedule and the same eco-genetic anchor as Phase H.

| condition | topology | effective support | role |
|---|---|---|---|
| `intact_control` | intact 4-edge network | intact-derived = 1 | positive opening control |
| `partner_loss_no_rescue` | 3-edge loss network | loss-derived | negative opening control |
| `topology_only_null` | Phase-H rewired 5-edge network | held to no-rescue loss support | representation-null audit |
| `partial_support_only` | 3-edge loss network | Phase-H rewiring support schedule | partial support intervention |
| `coupled_rewiring_replay` | Phase-H rewired network | Phase-H rewiring support schedule | representation replay |
| `full_support_delayed` | 3-edge loss network | rises from loss support to 1 over the same 10-generation window | support magnitude under matched recovery timing |
| `full_support_immediate` | 3-edge loss network | 1 from generation 1 | positive representation control / no-delay recovery |

No condition value is selected from Phase-I outcomes.

## Opening rule

Interpret Phase I only if:

1. fresh `intact_control` is `R4_highrep`;
2. fresh `partner_loss_no_rescue` is `R3_highrep`.

Otherwise record `not_opened` and stop. Do not change seeds, support schedules, recovery window, partner-loss identity or R4 thresholds.

## Representation audits

Before causal interpretation, require:

- `topology_only_null` and `partner_loss_no_rescue` to have identical biological loss outcomes because their effective-support schedules are identical;
- `partial_support_only` and `coupled_rewiring_replay` to have identical biological loss outcomes because their effective-support schedules are identical;
- `full_support_immediate` and `intact_control` to have identical biological loss outcomes because the life cycle receives the same support multiplier (=1) at every post-baseline generation.

Failure of any identity is a code/representation failure, not an ecological result.

## Causal classification

After the opening and representation audits:

- `partial_support_only = R4` → `partial_support_sufficient`;
- partial remains R3 but `full_support_delayed = R4` → `support_magnitude_limiting`;
- partial and delayed-full remain R3 but `full_support_immediate = R4` → `recovery_timing_path_dependence`;
- immediate-full fails to match intact → `positive_control_failed` and no ecological interpretation.

The key distinction is therefore **how much support is restored** versus **how long the system experiences reduced support before restoration**.

## Why this is not rewiring-strength tuning

Phase I does not search a rewiring fraction. The Phase-H partial-support schedule is replayed once as a fixed intervention. Full support is a mechanistic control, not a fitted candidate value. The 10-generation delayed-full trajectory uses the already-declared Phase-H recovery window.

No intermediate support levels or alternative windows are opened after results.

## Interpretation ceiling

Phase I cannot establish an independent effect of connectance or topology because the current life cycle contains no independent topology channel. A true topology-effect test would require a new prospective closure in which topology changes another biological operator (for example partner-demographic reliability, functional complementarity, interaction variance or coextinction dynamics) in addition to aggregate support.

Phase I also does not model pollen, seed/propagule, demographic or partner movement.

## Stop rule

Classify the seven predeclared conditions once. Do not tune support levels, recovery window, network scores/capacities, partner-loss identity, seeds or R4 thresholds after observing the result.
