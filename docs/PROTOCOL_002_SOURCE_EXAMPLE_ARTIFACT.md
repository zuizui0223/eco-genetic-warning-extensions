# Protocol 002 source-skeleton example artifact

## Purpose

This artifact fixes the first committed example output for the Stage I
source-runner skeleton.

It is generated by the same schema used by:

```bash
protocol002 write-source-skeleton-example
```

and the test suite requires the committed JSON to match
`example_source_skeleton_artifact()` exactly.

## Artifact

```text
artifacts/protocol002/source_skeleton_example_manifest.json
```

## Interpretation

The artifact contains one explicit `not_run` source-attempt record. It is not a
source reconstruction result and it is not Type S ecological evidence.

The artifact must retain:

```text
simulation_result_present = false
```

## Next gate

After this artifact is fixed, the next implementation step is a Stage I source
coordinate enumerator that writes planned attempt rows only. It must still not
run source reconstruction.
