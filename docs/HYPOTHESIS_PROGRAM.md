# Independent hypothesis program

## What this repository is for

`eco-genetic-warning-extensions` is **not** a backlog or continuation branch for
`eco-genetic-criticality`. The predecessor repository is complete for its own
finite closure and remains its own canonical evidence record.

This repository uses boundaries exposed by that completed program to submit and
test **new hypotheses under newly declared biological closures**. A predecessor
result may motivate an extension, but it is neither an unfinished result nor
numerical evidence for the extension.

## Research logic

```text
completed finite closure
-> explicitly identified boundary
-> new biological closure
-> new hypothesis with fresh protocol
-> independent calibration and validation
-> new Type S evidence statement
```

The question is not “does the old result finally hold more generally?” It is:

> What distinct dynamical proposition follows, if at all, after this specific biological mechanism is changed?

## Protocol 001 hypothesis

Protocol 001 changes the recurrent mutation closure from symmetric state
transitions to direction-specific recurrent mutation while holding total
one-generation mutation pressure fixed across the SYM, UP, and DOWN panels.

Its new hypothesis is:

\[
\textbf{H2-R-AS:}\qquad
\tau_{\Delta H_x(r)} < \tau_T,
\quad x\in\{\alpha,\gamma\},\quad r\in\{0.05,0.10,0.20\},
\]

for a domain independently selected by realised trait-loss calibration **within
each declared mutation-direction closure**.

H2-R-AS is not a robustness patch for H2-R. It is a new, closure-conditional
dynamic hypothesis about whether directionally biased recurrent mutation changes
the ordering between genetic erosion and realised trait loss.

## Interpretation discipline

- A successful SYM panel is a bridge/reproducibility control, not a claim that
  the predecessor was incomplete.
- UP and DOWN are separate directional-mutation hypotheses, not sensitivity
  settings selected to rescue a desired warning result.
- A panel with no H1-prepared, calibration-selected domain yields an informative
  boundary result: this hypothesis is not evaluable under that declared closure
  and candidate family.
- Results are reported separately per panel. They do not combine into a claim of
  universal warning behavior.

## Future protocols

Every future protocol must begin with a one-sentence new hypothesis, name the
single changed closure or explicitly justified closure bundle, and state why the
result is not an unfinished component of an earlier repository.
