# Phase Q — high-precision validation of the Phase-F interaction-support result

The historical Phase-F result reported R4 at all three predeclared scalar interaction-feedback levels, but each five-block classification used only about 12–19 eligible trajectories per block. Phase J showed that the hard all-five-block gate is unstable at that precision.

## Fixed design

- master seeds `20290510–20290514` only;
- interaction kappa `3.0, 4.5, 6.0` only;
- independent source reconstruction for each kappa exactly as Phase F;
- 100 attempted replicates per seed×kappa;
- historical `[0.30,0.70]` gate unchanged;
- no warning/diversity outcomes used.

## Prefix gate

All 15 seed×kappa first-20 eligible/loss prefixes must exactly reproduce Phase F before interpretation.

## Decision

If all three kappas remain R4 at high precision, the bounded Phase-F robustness result is confirmed with reliable block precision. If any leaves R4, replace the historical all-R4 interpretation with the full high-precision map rather than tuning kappa.

## Stop rule

No replacement seeds, new kappa levels, changed R4 band or further precision escalation merely to preserve the historical all-R4 result.
