# Condition-recovery closure before manuscript rewrite

## Status

The warning-blind condition-recovery phase is closed for the current manuscript cycle.

No additional `p_star` or migration tuning is permitted merely to widen an evaluable warning domain. The current model does not contain a clean exogenous pollinator/mutualist-availability parameter, so an additional abstract sweep of `interaction_feedback` would not be treated as an empirical pollinator-support test.

## Recovered hierarchy

1. **Functional-state mechanism — recovered.** Interaction feedback can support distinct functional states in the declared closure.
2. **Fragmentation route — recovered.** Fragmentation of the same prepared high-function state reduces interaction support, local effective size and realised high-trait mass.
3. **Conditional genetic precursor — recovered.** Relative genetic erosion precedes observed realised functional loss in one independently calibrated symmetric benchmark; fixed absolute thresholds are not robust.
4. **Recurrent-transition condition map — recovered.** Recurrent state turnover changes source feasibility and reorganises rapid-loss, persistence and seed-heterogeneous regimes.
5. **Warning-evaluable event regime — positively recovered.** The original coarse 15-coordinate grid had 15/15 no-domain outcomes, but prospective warning-blind refinement recovered and independently replayed R4-highrep at `kappa_mu=0.35, p_star=0.35` under the fixed B1 ecological/deterioration anchor.
6. **R4 width — bounded.** Neighboring `p_star=0.325` and `0.375` were R3-highrep; no finer `p_star` tuning is opened.
7. **Connectivity boundary — recovered at one R4 anchor.** Allele-frequency migration `m=0,0.025,0.05` retained R4-highrep; `m=0.10,0.20` produced R3-highrep. Paired trajectories switched loss status in both directions, so migration is not a universal rescue/collapse operator.
8. **Direction-only warning effect — not opened.** A contiguous matched R4 interval along recurrent-transition direction was not recovered, so no new H-MD-3b warning test is justified.
9. **Portability — bounded historical result.** Protocol 003 shows that warning availability/ordering differ across separately recalibrated non-matched domains, without identifying a direction-only effect.

## Scientific conclusion of the condition phase

The finite model now supports a stronger conclusion than the original 15/15 no-domain result:

> **Genetic-warning estimability occupies a bounded eco-genetic regime. It requires not merely intermediate average functional-loss risk, but reproducible nondegenerate loss across independent stochastic blocks. Recurrent state turnover determines where that regime lies, and effective genetic connectivity can move a fixed biological anchor into or out of it.**

This is a condition result, not a claim that the genetic warning succeeds everywhere R4 occurs.

## Why the simulation search stops here

A further model campaign would need a clean biological axis not already covered by the recovered evidence. Urban and island applications motivate pollinator/mutualist support and reproductive assurance, but the current simulator does not expose those as independent external controls. Treating `interaction_feedback` as a direct pollinator-availability proxy would confound feedback strength with the state mechanism itself.

Therefore the next step is manuscript rewriting, not another parameter sweep.

## Manuscript handoff

The publication source should now follow four questions:

1. How is interaction-dependent function maintained and lost under fragmentation?
2. Can genetic erosion precede that functional loss?
3. Under what eco-genetic conditions is that warning comparison estimable?
4. Once estimable, is the warning portable across regimes, and why should portability be limited?

The central new result is Question 3, including both the narrow R4 recovery and Phase-E connectivity boundary.
