# Phase N — high-precision validation of the Phase-G partner-loss claim

Phase L showed that the three historical Phase-G R3 labels do not by themselves identify biological block heterogeneity. Phase N precision-expands the exact historical partner experiment.

## Fixed design

- master seeds `20290610–20290614` only;
- architectures unchanged: intact, even, graded, dominant;
- exact historical lost-partner assignment and retained-support function;
- 100 attempted replicates per master seed;
- conditions paired on the same prepared source/trajectory seed;
- historical `[0.30,0.70]` five-block gate unchanged;
- no warning/diversity information used.

## Prefix gate

For all 20 seed×architecture blocks, the first 20 attempted replicates must exactly reproduce the locked Phase-G eligible/loss counts. Any mismatch blocks interpretation.

## Readouts

1. full-precision R1–R4 classification for all four architectures;
2. equal-rate and finite-sample gate diagnostics at the full block sizes;
3. paired loss-status switches and exact McNemar evidence for each loss architecture versus intact.

If all historical loss R3 labels become R4, withdraw the claim that partner loss changes warning estimability/reproducibility through an R4→R3 transition. A paired marginal incidence effect, if present, remains a separate biological result.

## Stop rule

No replacement seeds, partner-weight changes, architecture refinement, R4-band changes or further precision increase merely to preserve historical R3 labels.
