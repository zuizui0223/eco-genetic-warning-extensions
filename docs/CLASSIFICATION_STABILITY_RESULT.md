# R4 classification stability result: the hard gate is ensemble-sensitive

## Result

Phase J held the full biological condition fixed at the nominal Phase-E/Phase-I `m=0.10` anchor and generated 20 fresh master-seed blocks. All blocks met the predeclared baseline-eligibility requirement.

The four prospectively fixed five-block panels classified as:

| panel | seed-block loss rates | regime |
|---|---|---|
| 1 | 0.474, 0.353, 0.389, 0.684, 0.438 | R4-highrep |
| 2 | 0.500, 0.647, 0.471, 0.375, **0.750** | R3-highrep |
| 3 | 0.563, 0.438, 0.412, 0.400, 0.526 | R4-highrep |
| 4 | 0.611, 0.526, 0.667, 0.625, 0.647 | R4-highrep |

The prospective stability classification is therefore:

> **`ensemble_sensitive`**

No seeds were added, removed or regrouped after the result.

## The biological distribution is much less discontinuous than the categorical label

Across all 20 fresh seed blocks:

- 19/20 observed loss rates were inside `[0.30,0.70]`;
- 0/20 were below the band;
- 1/20 was above it (`12/16 = 0.75`);
- mean block loss rate = `0.525`;
- median block loss rate = `0.513`;
- range = `0.353–0.750`.

Thus three panels were labelled R4 and one R3 even though the fixed condition produced a broadly intermediate-risk block distribution centred near 0.5. The categorical difference was generated by whether the single upper-tail block appeared in a given five-block panel.

## Exact design dependence of the all-block gate

Let `X_i=1` if a seed block's observed loss rate lies in the operational intermediate-risk band and let

`q = P(X_i=1)`.

The historical R4 rule accepts a `B`-block panel only if every block passes:

`G_B = product_i X_i`.

For independent exchangeable blocks,

`P(G_B=1) = q^B`.

For every `0 < q < 1`, this probability decreases strictly as panel size `B` increases. Therefore the all-block gate is **mechanically panel-size dependent** unless every possible block always passes or always fails.

This is a design property of the classifier, not a biological effect.

## Exact all-combinations audit of Phase J

Phase J contains 20 block rates, of which exactly 19 pass the band and one fails high. There are

`C(20,5) = 15,504`

possible unordered five-block panels.

A panel is R4 exactly when it excludes the one failing block:

- R4 panels: `C(19,5) = 11,628` = **75%**;
- R3 panels: `C(19,4) = 3,876` = **25%**.

The observed prospective grouping—three R4 panels and one R3 panel—is therefore not an anomalous contradiction. It exposes the expected grouping dependence of an all-block pass rule when rare tail blocks exist.

The observed single-block pass fraction is `19/20 = 0.95`; its 95% Wilson interval is approximately `0.764–0.991`. The plug-in independent five-block pass propensity is `0.95^5 = 0.774`, close to the exact without-replacement all-combinations fraction of 0.75.

## Reinterpretation of Phase E and Phase I

Phase E and Phase I remain valid locked finite campaigns:

- Phase E `m=0.10`: block rates `0.667, 0.722, 0.600, 0.556, 0.600` → R3;
- Phase I `m=0.10`: block rates `0.412, 0.500, 0.579, 0.500, 0.500` → R4.

Their categorical disagreement no longer supports treating `m=0.10` as a portable biological boundary. Instead, both are compatible with a fixed condition whose stochastic block-level loss distribution is usually intermediate but has nonzero tail probability.

The robust Phase-E conclusion that remains is that changing connectivity reshuffled paired functional-loss histories in both directions. The stronger claim that `m=0.10–0.20` defines a stable R4→R3 boundary must be downgraded unless independently replicated with a sampling-design-invariant estimand.

## Revised interpretation of R4

R4 should now be described as a **panel-level calibration certificate under a specified sampling design**, not as a sample-size-invariant biological regime label.

The biological object of interest is instead the **distribution of loss risk across stochastic blocks**. Two separate quantities should be reported:

1. central event incidence — where the block-level loss distribution is centred;
2. reproducibility / tail behaviour — how much of that distribution falls into near-persistence or near-deterministic-loss regions.

For the current operational band, a natural continuous diagnostic is the **block evaluability fraction**: the probability/fraction that an independently generated block lies inside `[0.30,0.70]`. This quantity should be reported with uncertainty rather than collapsed immediately into an all-block yes/no gate.

The old R4 certificate can remain as a conservative protocol rule for deciding whether a particular finite warning-validation panel is opened. It should no longer carry the full biological interpretation by itself.

## Why this strengthens the warning-estimability framework

The central conceptual result survives and becomes sharper:

> Warning performance is downstream of the distribution of functional-loss events, but the estimability of that distribution must itself be quantified with sampling uncertainty.

This matches the broader early-warning literature, which emphasizes that warning reliability depends on the transition mechanism, sampling design and uncertainty rather than on a deterministic threshold alone.

The updated hierarchy is therefore:

```text
functional state feasibility
        ↓
functional-loss distribution
        ├─ central incidence
        └─ among-block heterogeneity / tail probability
        ↓
finite-panel calibration certificate (legacy R4 gate)
        ↓
only then: genetic-warning availability and timing
```

## Stop decision

**Phase J is closed.** Do not add or regroup seed panels to make the categorical gate stable.

The next methodological task is not another biological parameter sweep. It is to promote block-level event incidence and heterogeneity to the primary estimands and demote the historical all-block R4 rule to a finite-panel opening certificate. Only after that revision should additional movement mechanisms be compared.
