# Phase V no-outcome-tuning rule

The Phase-V scientific comparison is deliberately a single maximal alignment contrast with fixed existing-model dynamics. Once a scientific workflow reaches the execution step, the following are not permitted in response to the observed result: replacement master seeds, a longer horizon, a different barrier schedule, additional alignment permutations, altered q/p/trait marginals, changed feedback weights, changed alpha, or increased replication.

Corrections are allowed only for demonstrable implementation/contract errors that prevent the preregistered design from being executed as written; any such correction must leave the declared scientific inputs unchanged and be documented before interpretation.
