# Cross-origin minimal bridge — public-metadata Stage A result

## Decision

**`minimal_bridge_origin_replication_not_met_from_locked_archives`**

The preregistered four-archive programme can stop before raw outcome access because one locked island archive fails an allowed Stage-A criterion from explicit public metadata alone.

This is not an ecological null and no reproductive outcome values were inspected or modelled.

## Locked candidate set

The candidate lock remains unchanged:

- `U1_commelina` — Dryad `10.5061/dryad.pd775`;
- `U2_chicago` — Dryad `10.5061/dryad.44j0zpcm6`;
- `I1_hiraiwa2017` — Dryad `10.5061/dryad.pm29d`;
- `I2_hawaii2019` — Dryad `10.5061/dryad.tm575v4`.

No fifth archive is added and no locked candidate is replaced.

## Stage-A metadata audit

The preregistration allows file names, metadata/README definitions and join feasibility to be inspected before any reproductive outcome value is opened.

### `U1_commelina`

Public Dryad metadata describes:

- `DataUshimaru_etalFig2.csv` as pollinator visitation data;
- `DataUshimaru_etalFigs34.csv` as pollen-counting data;
- `DataUshimaruetalFigs43.csv` as floral-trait and pollen-removal data.

The source paper reports pollinator visit frequency and male/female reproductive success across 12 populations. Public metadata therefore does not fail the existence-of-process/existence-of-reproduction screen, but exact same-unit mapping and join keys remain unresolved without verified archive bytes.

**Metadata status: `mapping_unresolved_without_verified_bytes`.**

### `U2_chicago`

Public Dryad metadata explicitly describes:

- `gopro_obs.csv` / `inperson_obs.csv` with site, plant, observation duration, flowers observed and pollinator visit counts;
- `tomato_fl.csv` / `squash_fl.csv` with site, individual, treatment, flowers and harvested/failed fruits;
- `tomato_seeds.csv` / `squash_seeds.csv` with site, individual, treatment and seed outcomes.

This archive therefore publicly demonstrates a visitation quantity with effort, realised reproduction and apparent site/individual join structure. Exact mapping is still frozen until verified bytes are available.

**Metadata status: `eligible_for_exact_mapping_if_bytes_verified`.**

### `I1_hiraiwa2017`

Public Dryad metadata describes `primary_data.xlsx` as plant–pollinator interaction data. The source article reports site/survey visitation and fruit-set analyses in three dominant plant species, and states that the paper data are accessible through the same Dryad archive. This is sufficient to keep the archive alive at the metadata screen, but it does not prove the exact fruit-set columns or join keys without opening the verified workbook.

**Metadata status: `mapping_unresolved_without_verified_bytes`.**

### `I2_hawaii2019`

Public Dryad metadata lists only:

- `Pollination visitation obs for dryad.xlsx`;
- `README_for_Pollination visitation obs for dryad.docx`.

Its usage note explicitly defines the deposited dataset as **raw data from flower visitation observations**. The source paper reports bagging/manual-treatment seed-set results, but the locked Dryad archive does not publicly identify a realised reproductive-response table/file. Under the preregistered Stage-A rule, an archive must separately demonstrate a realised reproductive endpoint from the same or defensibly joinable ecological unit.

Because the response component is not demonstrated in the locked archive metadata, `I2_hawaii2019` fails Stage A without any need to inspect outcome values.

**Metadata status: `minimal_bridge_not_identifiable_from_archive`.**

## Consequence for the cross-origin programme

The preregistered origin comparison requires at least two independent island systems and two independent urban systems to pass the same response-semantic gate. Once `I2_hawaii2019` fails Stage A, the locked candidate set contains at most one island system that can still qualify.

Therefore the current four-archive programme cannot identify an urban–island origin contrast:

`n_island_eligible <= 1 < 2`.

The programme stops at:

**`minimal_bridge_origin_replication_not_met_from_locked_archives`.**

No archive is substituted after this result. In particular, a fifth study is not added merely to restore a two-versus-two contrast.

## What remains scientifically useful

- `U2_chicago` is a strong future within-system minimal-bridge candidate once exact bytes are verified.
- `U1_commelina` and `I1_hiraiwa2017` remain unresolved mapping candidates, not failures.
- the stronger full-state N1 hypothesis remains open and still requires matched `D/I/T/C/R/G/A` state semantics, common realised-function definitions and origin replication independent of study identity.

## Response firewall

No candidate reproductive outcome values were opened, summarized or modelled for this decision. The decision uses only the preregistered candidate lock, public archive file descriptions, public usage notes and source-paper statements about what classes of measurements were collected.
