# Nature Ecology & Evolution live submission checklist — 2026-09-05

## Purpose

Record the journal-facing completion gate for the active flagship without turning submission formatting into new scientific analysis.

## Initial-submission format

Current Nature Ecology & Evolution guidance allows initial submissions in PDF, Word or TeX/LaTeX and does not require full final-production formatting at first submission. The review-facing scientific content and readability therefore take priority over journal-style cosmetics.

Current flagship internal Article contract:

- [x] Article content type selected;
- [x] abstract <=200 words under automated check;
- [x] main text <=3,500 words excluding Methods under automated check;
- [x] five main display items, below the six-item ceiling;
- [x] core bibliography below the ~50-reference working guideline;
- [x] unheaded Introduction followed by Results, Discussion and Methods;
- [x] manuscript accessible to non-specialist ecological/evolutionary readers in title and framing.

## Required scientific material

- [x] detailed findings in one flagship manuscript;
- [x] Methods sufficient to interpret the four evidence layers;
- [x] exact source repositories/commits pinned for all load-bearing results;
- [x] deterministic figure generation from locked evidence;
- [x] cover letter explaining one general advance rather than repository history;
- [x] bibliography including forecasting, forecast horizon, multilayer ecology, early-warning validation, indicator validation and natural-system sources;
- [x] nearest-neighbour positioning against Song & Levine model validation and Ovaskainen et al. real-time forecasting;
- [x] explicit claim boundaries preventing unsupported causal integration;
- [x] no simultaneous submission of substantially overlapping fallback manuscripts.

## Data and code availability

Before portal submission:

- [ ] create permanent reviewer-accessible snapshots for the exact pinned EGC, EGWE and EGWEE evidence states or one cross-referenced archive collection;
- [ ] verify every load-bearing machine-readable result in the flagship source manifest is publicly accessible or available to editors/reviewers;
- [ ] write reader-facing `Data availability` and `Code availability` sections using permanent URLs/DOIs rather than mutable branch links where possible;
- [ ] ensure third-party natural datasets are cited rather than redistributed when licences/provenance require source access;
- [ ] retain the checksum manifest linking the integrated submission packet to each source evidence object.

## Reporting / analytical transparency

If the paper is selected for peer review, complete any requested Nature Portfolio reporting-summary or editorial-policy checklist using the already frozen design records.

The reporting material should state, as applicable:

- [x] prospective versus retrospective status of each analysis is explicitly separated;
- [x] sample/trajectory denominators are reported rather than inferred from threshold-endpoint records;
- [x] nested 500/1,000/1,500 propagation prefixes are not treated as independent experiments;
- [x] no generation-20 significance crossing is treated as a selected biological cutoff;
- [x] warning evaluation retains event and non-event units under one common horizon;
- [x] natural analyses use ecological holdout units rather than observation-level random splits;
- [x] STOP / not-identifiable outcomes are retained rather than repaired post result;
- [x] no pooled effect-size meta-analysis is claimed across heterogeneous natural systems.

## AI / automated-tool disclosure

Current Nature Ecology & Evolution preparation guidance states that large language models do not qualify for authorship and that use of an LLM should be properly documented in the Methods section (or another suitable section if no Methods exists). Human authors remain responsible for the work.

Before submission:

- [ ] draft an accurate disclosure of actual AI/automated-tool use in manuscript development, coding, checking and/or language support;
- [ ] ensure the disclosure does not imply delegation of scientific accountability;
- [ ] ensure all numerical claims were independently anchored to locked evidence rather than accepted from generated prose;
- [ ] obtain author approval of the exact disclosure wording.

## Overlap / fallback gate

The standalone EGC, EGWE-state, EGWE-warning and EGWEE packages are not abandoned; they are frozen fallback routes.

While the flagship is active at Nature Ecology & Evolution:

- [ ] no substantially overlapping fallback manuscript is simultaneously under consideration elsewhere;
- [ ] no preprint or repository-facing manuscript is described as a separately submitted paper if doing so creates misleading duplicate-publication status;
- [ ] if the flagship is rejected/withdrawn, reactivate fallback manuscripts only after checking what material from the flagship is publicly disclosed and what the next journal requires.
