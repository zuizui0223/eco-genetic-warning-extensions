## Material excluded from the scientific narrative

Keep implementation history, intermediate PR failures, temporary GitHub Actions outages, and debugging chronology out of both the main paper and scientific supplement. Preserve them only in repository history.

## Editorial rule

A result stays in the main text only when it advances this causal story:

`fragmentation and interaction change -> eco-genetic state change -> possible genetic warning -> transition-direction dependence of warning feasibility and reliability`.

Everything else supports reproducibility, robustness, or scope and belongs in the supplement.
