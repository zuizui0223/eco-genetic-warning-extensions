# Eco-genetic warning extensions

This repository tests **when an eco-genetic warning question is biologically well posed**. It is the condition-recovery extension of [`eco-genetic-criticality`](https://github.com/zuizui0223/eco-genetic-criticality), pinned for inherited scientific results at `dd8ee379d0d3518194c767d16402042525bc00dc`.

The repository is now organised condition-first rather than protocol-first:

```text
C0  Can an interaction-dependent high-function state exist?
        ↓
C1  Does fragmentation / deterioration disrupt that state?
        ↓
C2  Which biological conditions generate reproducible functional loss?
        ├─ recurrent state turnover
        ├─ effective genetic connectivity
        └─ aggregate interaction support
        ↓
C3  Only inside an evaluable loss regime: does genetic change precede loss?
        ↓
C4  Is that warning portable across eco-genetic regimes?
```

**Warning is therefore a downstream conditional outcome, not the starting hypothesis.** If a general hypothesis is not recovered, the next result is the boundary or condition under which it is recovered.

## Current scientific state

### Inherited mechanism

The parent repository supplies the mechanistic base:

- interaction feedback can support distinct low- and high-function states in the declared canonical model;
- fragmenting the same prepared high state reduces interaction, local effective size and realised high-trait mass;
- in one independently calibrated symmetric benchmark, relative genetic-diversity erosion preceded observed functional loss, whereas fixed absolute thresholds produced both leads and lags.

Parent and extension trajectories are never pooled.

### Recovered extension results

1. **Source feasibility is conditional.** Across the original 15 recurrent-transition coordinates, 2,269/3,375 source attempts supported preparation/projection; support varied from 44.89% to 86.67%.
2. **Functional-loss regime is conditional.** Among 648 complete common-grid candidates, 322 were rapid-loss, 242 persistence and 84 seed-heterogeneous.
3. **The original common grid contained no strict warning-evaluable domain.** All 15 coordinates remain historically `no_domain_selected`; this is an event-regime result, not warning failure.
4. **A warning-evaluable event regime does exist, but narrowly.** Prospective warning-blind Phases C/D independently recovered R4 at `kappa_mu=0.35, p_star=0.35`; neighbouring `p_star` values remained seed-heterogeneous.
5. **Genetic connectivity changes evaluability without acting as a universal rescue axis.** Phase E kept the recovered anchor fixed: `m=0–0.05` remained R4-highrep, whereas `m=0.10–0.20` became R3-highrep, with loss-status switches in both directions.
6. **Portability is bounded.** The historical Protocol 003 domains differ in several ecological and recurrent-transition parameters; their warning contrast is therefore a portability result, not a matched direction-only causal effect.

All numerical conclusions are finite Type S evidence for the declared model closure.

## Active missing condition test: aggregate interaction support

The next unresolved ecological condition is interaction support around the independently recovered R4 anchor. Phase F is prospectively fixed to the **existing Protocol 002 interaction-feedback values** `kappa = 3.0, 4.5, 6.0`, with fresh seeds and independent source reconstruction at every kappa.

This parameter is an aggregate positive-feedback strength. It is **not** partner richness, connectance, pollinator diversity, or interaction-network dimensionality. The present model can therefore test whether weaker/stronger effective interaction support changes source feasibility and functional-loss regime, but it cannot yet claim that network simplification itself has been simulated.

No finer kappa search is allowed merely to create or widen R4.

## Urban and island translation

Urban and island systems are treated as contrasting empirical tests of the same condition map, not as decorative applications.

The model-facing variables are kept separate:

- spatial fragmentation / local habitat support;
- realised interaction support;
- effective genetic connectivity;
- reproductive assurance or functional redundancy;
- realised functional loss;
- genetic state through time.

This permits a common question: **when does spatial fragmentation become functional fragmentation?** Cities and islands may reach similar eco-genetic regimes through different mechanisms. A decline in partner richness is one possible mechanism, but interaction-network simplification is not assumed from patchiness alone.

See [`manuscript/urban_island_regime_tests.md`](manuscript/urban_island_regime_tests.md) for the empirical translation and measurement design.

## Stop rules

- Do not tune `p_star`, migration, interaction kappa, or the R4 gate merely to obtain a desired warning result.
- Do not inspect warning/diversity fields while selecting an event regime.
- Do not call allele-frequency mixing demographic, pollen or seed dispersal.
- Do not call interaction `kappa` network simplification.
- If a conceptual hypothesis is not general, report the recovered condition/boundary instead of widening the search until it appears true.
